# Development Dependencies

# Exact pins, matching the convention `requirements.txt` already sets for
# runtime. This file had none: every entry was a lower bound, so two people
# following CONTRIBUTING could run different tools and get different results
# from the same tree.
#
# The concrete case was ruff. CI installed `ruff==0.15.1` from a literal in
# test.yml while this file said `ruff>=0.1.0`, so a contributor who installed
# from here got whatever was current and could pass locally while the gate
# failed — or worse, reformat the tree to a different style. The workflow now
# reads the pin from this file, so the two cannot drift apart again.
#
# Pins also make the tier-2 record honest. It states a test count against an
# upstream pin (`tests/fixtures/vendor/kfx_input_plugin.lastrun.json`), and a
# count is only evidence if the next person can reproduce it.
#
# Bump deliberately, one line at a time, and re-run the suite.
